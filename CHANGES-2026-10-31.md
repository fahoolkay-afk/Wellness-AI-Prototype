# Changes 2026-10-31

### Split into two projects, with a shared bridge sync kit
- The front desk and the EHRM are now developed in separate chats. `bridge-sync/` holds the shared files, identical in both
  projects:
  - the contract (v1.2);
  - `CONTRACT.lock.json`: fingerprint, event types, capabilities, routes, form crypto, consent versions;
  - `joint-check.mts`: compares both allow-lists, then runs both apps together in memory over signed HTTP;
  - `README.md`: the rules for changing the bridge.
- `CLAUDE.md`: the owner's working rules, loaded by a new chat. `HANDOFF.md`: state, open items and a starter message.
- Test: `test/bridge-sync.test.ts` (the kit's contract and `docs/` match the lock; the event table and form crypto match the
  lock). Suite: 111 pass.
- Joint check with the EHRM: 17 of 17 (in sync). A deliberate drift in a scratch copy of the EHRM (one service code renamed)
  failed J6, as it should.
